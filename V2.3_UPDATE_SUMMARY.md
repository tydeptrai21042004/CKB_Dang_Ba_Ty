# CKBuilder v2.3.0 update summary

## Added

- Five official beginner tutorial tracks:
  - Transfer CKB
  - Store Data on Cell
  - Create a Fungible Token
  - Create a DOB
  - Build a Simple Lock
- A deterministic local practice library and CLI.
- Evidence templates for every tutorial.
- A screenshot guide for Windows, macOS, and Linux.
- CCC App, CCC Playground, examples, and API resources.
- Rust SDK, CKB-CLI, Go, Java, Faucet, Debugger, and CKB Tools resources.
- Fiber documentation/showcase and Perun CKB source links.
- New Learning Hub tutorial, resource, and screenshot-safety panels.

The local exercise runner demonstrates that the repository code works offline. It does not create real CKB transactions and does not count as official tutorial completion. Use Devnet or Testnet for the official tutorials, save screenshots, and create each `completion.md` file from its template.
