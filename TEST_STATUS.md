## Runtime CI versus release CI

Use this while the local stack is running:

```bash
npm run ci:runtime
```

A running tree may legitimately contain `.env`, `secrets/`, `node_modules/`, logs, SQLite files, and PID/state files.

Use this only against a **clean release copy/archive**:

```bash
npm run ci:local
```

`ci:local` adds `scripts/audit-release.sh`, which intentionally rejects runtime/private artifacts from a distributable release.
