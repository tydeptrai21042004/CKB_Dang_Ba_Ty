# CKBuilder v2.4.0 Update Summary

## Release goal

Version 2.4.0 improves the browser experience and turns the learning directory into a usable study system while preserving evidence integrity. It does not mark a course, tutorial, or on-chain exercise complete unless the learner creates the required evidence record.

## UI improvements

- Redesigned Learning Hub hero with current progress, guided hours, module count, and next recommended lesson.
- Search across titles, summaries, outcomes, and tags.
- Category filters for foundations, transactions, tooling, smart contracts, scaling, and projects.
- Prerequisite-aware states: available, planned, and complete.
- Detailed lesson dialog containing learning outcomes, checkpoints, practical activities, commands, references, and evidence expectations.
- Copy buttons for lesson commands.
- Persistent light/dark theme.
- Improved sidebar progress meter, visual hierarchy, spacing, keyboard behavior, focus treatment, and mobile responsiveness.
- Safe DOM construction without dynamic `innerHTML`.

## Learning content added

The `learning/curriculum/` directory now contains 14 modules:

1. CKB fundamentals
2. Capacity and Cell data
3. Transaction anatomy
4. Locks and Type Scripts
5. Addresses and hashes
6. RPC and Indexer
7. CCC basics
8. CCC transaction construction
9. Molecule serialization
10. CKB-VM and RISC-V
11. Rust script development
12. Testing and debugging
13. Fiber and Perun payment channels
14. Capstone planning

Every module has `README.md`, `QUIZ.json`, and `EVIDENCE_TEMPLATE.md`. The release contains 42 curriculum questions in total.

Additional learner resources:

- `learning/STUDY_PLAN.md` — eight-week sequence
- `learning/GLOSSARY.md` — concise CKB terms
- `learning/DEV_LOG_TEMPLATE.md` — weekly evidence log
- `learning/CAPSTONE_BRIEF_TEMPLATE.md` — project planning worksheet
- `docs/SCREENSHOT_EVIDENCE_GUIDE.md` — safe screenshot instructions
