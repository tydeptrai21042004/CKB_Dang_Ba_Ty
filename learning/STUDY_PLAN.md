# Eight-Week CKBuilder Study Plan

The handbook expects steady weekly progress. This plan uses approximately 4–5 hours per week and can be adjusted without backfilling reports later.

| Week | Focus | Required output |
|---|---|---|
| 1 | CKB fundamentals, capacity, and data | Modules 01–02, quiz results, dev-log entry |
| 2 | Transactions, scripts, addresses | Modules 03–05, annotated transaction |
| 3 | RPC, indexer, CCC basics | Modules 06–07, one read-only RPC and CCC screenshot |
| 4 | CCC transactions and official DApp exercises | Module 08 and at least two official tutorials |
| 5 | Molecule and CKB-VM | Modules 09–10, decoder evidence and cycle notes |
| 6 | Rust scripts | Module 11, contract test evidence |
| 7 | Testing, debugging, payment channels | Modules 12–13, defect report and architecture notes |
| 8 | Capstone planning and consolidation | Module 14, capstone brief, final weekly report |

## Weekly rhythm

1. Read one or two official references.
2. Run the local lab and quiz.
3. Complete a real tutorial where applicable.
4. Save redacted screenshots immediately.
5. Publish one honest dev-log entry for the week.
6. Record the next concrete action.
