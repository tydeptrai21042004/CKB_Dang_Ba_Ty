# CKBuilder Structured Curriculum

This folder contains a fourteen-module path from CKB fundamentals to a scoped capstone. Each module contains:

- `README.md` — lesson, lab, checkpoints, and references;
- `QUIZ.json` — a runnable local knowledge check;
- `EVIDENCE_TEMPLATE.md` — a safe completion-record template;
- `completion.md` — created by the learner only after genuine completion.

Run `npm run learning:quiz -- --list` to list quizzes, or `npm run learning:quiz -- <module-id>` to start one.

The curriculum does not automatically mark reading or local simulation as official tutorial completion.
