Verification workflow

Four independent checks

01
Issuer authenticity

Validate the trusted issuer, Ed25519 key binding, and credential signature.

02
Document integrity

Compare an uploaded certificate with the signed SHA-256 document hash.

03
Live Cell state

Read the matching `ACTIVE` or `REVOKED` record without signing a transaction.

04
State consistency

Reject duplicate, malformed, or conflicting off-chain and on-chain evidence.

Protocol boundary

The Type Script enforces irreversibility for one Cell lineage. It does not guarantee global uniqueness against an independently created Cell with the same credential hash; the inspector reports multiple live matches as a conflict.
