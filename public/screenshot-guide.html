Proof of participation

Screenshot evidence guide

Capture evidence while completing each tutorial. Keep the result visible and all secrets hidden.

Minimum evidence per tutorial

  1. Setup: Devnet/Testnet, terminal command, or running tutorial app.
  2. Success: transaction hash, committed status, successful build, or script result.
  3. Verification: changed balance, decoded Cell data, issued token, created DOB, or successful unlock.

Windows

  1. Press Win + Shift + S.
  2. Select Rectangular Snip.
  3. Capture only the relevant terminal or app area.
  4. Review and redact secrets before saving the PNG.

Safe filenames

screenshots/learning/transfer-ckb-01-setup.png
screenshots/learning/transfer-ckb-02-success.png
screenshots/learning/transfer-ckb-03-verification.png

Never capture

  • Private keys from offckb accounts
  • Seed phrases, passwords, tokens, or .env values
  • Personal tabs, email, chat, account names, or notifications

Finish the evidence record

Copy the tutorial's EVIDENCE_TEMPLATE.md to completion.md, fill every field, add the screenshots to your weekly dev log, then run:

npm run learning:check
